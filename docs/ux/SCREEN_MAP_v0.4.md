# Screen Map — v0.4

## Mobile

`Home` → Biblioteca | Dispositivo | Sincronização | Estatísticas | Configurações.

`Biblioteca` → deck list, card count, create/open/manage deck. No learning statistics.

`Dispositivo` → identity, firmware/protocol/capacity, connection configuration.

`Conexão` → QR pairing, nearby network selection, credentials and provisioning. No deck selection.

`Sincronização` → desired deck presence and explicit BLE sync. Actual versus desired state is visible only as pending/synchronized state.

`Estatísticas` → all learning metrics.

## Terminal

`Home` → due summary, Start Session, Synchronization, Connection.

`Sincronização` → Sync now over backend, Phone/Bluetooth, Back.

`Conexão` → current Wi-Fi state, known-network count, Configure Network, Wi-Fi On/Off, Back.

`Bluetooth` → temporary waiting/connected screen with Cancel.

`Provisioning` → QR code, temporary SSID/password, Cancel.

Study question/answer/summary screens remain isolated from connectivity settings.
