# Mnemos v0.3.1

Versão corretiva do aplicativo móvel para o provisionamento Wi-Fi do terminal.

O fluxo deixa de exibir a exceção genérica `Null check operator used on a null value` para respostas incompletas do terminal/backend. Os parsers agora validam campos obrigatórios e identificam explicitamente o endpoint ou objeto inválido.

A tela de configuração passa a exibir a fase corrente do provisionamento e adiciona descoberta de SSIDs próximos no Android. A entrada manual permanece disponível como fallback. Nenhuma mudança de Device Protocol ou de firmware é necessária para esta versão.

O Device Protocol permanece v2 e os schemas permanecem v1.
