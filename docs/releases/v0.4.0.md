# Mnemos v0.4.0

v0.4.0 is the connectivity, desired-state synchronization and HMI simplification release.

The mobile Home becomes navigation-only. Learning metrics move exclusively to Statistics. Library removes maturity/progress presentation. Device identity/configuration and content synchronization become separate screens. Connection no longer transfers decks.

Synchronization now models a desired terminal state: each deck is either present on Mnemos or app-only. Reviews always return automatically. The backend stores desired state separately from last reported physical state.

The CYD firmware gains AP-only provisioning, persistent known network profiles, autoconnect selection with backoff, Wi-Fi radio off without credential loss, protocol v3, explicit Connection and Synchronization screens, and on-demand BLE direct synchronization using the canonical Mnemos schemas. Study sessions are also resumable after restart: the terminal persists the unfinished queue by stable card IDs and offers CONTINUAR SESSÃO without involving the mobile app.

The Android Wi-Fi scan groups dual-band BSSIDs by SSID and detects Enterprise security. BLE direct sync is implemented as an Android native GATT client. Public specifications add `mnemos.network-profile/v1`, Provisioning v2, Device Protocol v3, BLE Sync Transport v1 and a future-facing sync manifest.

Known limitations are documented: the CYD reference firmware supports only terminal card capability `basic/plain`; Enterprise certificate authentication and generic captive-portal automation are not implemented; delta content transfer is reserved by the manifest but v0.4 commits atomic full snapshots; production NVS/flash encryption remains a deployment hardening requirement.
