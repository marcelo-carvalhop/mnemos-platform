§5.9. Todos partem dos mesmos cards. A regra inteira da seção é uma linha: só a múltipla escolha entra no cronograma.
O selo é obrigatório
§5.9 exige rótulo ou cor consistente. Verde = conta. Âmbar = treino extra. Sem isso o usuário distorce o próprio cronograma achando que adiantou trabalho.
Nenhuma tela âmbar tem barra de graus — não há o que registrar.

4. AS DUAS
QUE FALTAVAM
Gerenciar baralho (§5.10) e assinatura (§5.13) — as últimas sem desenho. Cada uma existe por causa de uma distinção que é cara de errar.
Arquivar ≠ apagar
"Terminei esse curso" é o que quase todo mundo quer dizer quando procura o botão de apagar. Arquivar guarda tudo; apagar leva o histórico junto, e o §3 diz que o histórico é a fonte da verdade.
Assinatura ≠ paywall
O paywall é o momento de pedir. Esta tela é para quem já paga — conferir, restaurar num aparelho novo, ou sair. Misturar as duas vende para quem já comprou.
