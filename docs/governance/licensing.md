# Decisão de licenciamento

Este repositório ainda não seleciona automaticamente uma licença. Isso é intencional: escolher uma licença altera o que terceiros podem fazer com o código e com a especificação pública.

Antes de tornar o repositório público, decida separadamente a política do código e a política das especificações. Uma licença permissiva como Apache-2.0 costuma ser adequada quando se deseja permitir implementação e redistribuição com concessão explícita de patentes; MIT é mais curta e permissiva, porém não contém a mesma cláusula explícita de patentes. Se o objetivo for manter o código fechado, não adicione uma licença open source apenas por conveniência.

Após a decisão, adicione `LICENSE` na raiz, documente a licença no `README.md` e determine se os schemas e documentos em `spec/` usam a mesma licença ou uma licença documental distinta.
