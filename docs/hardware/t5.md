# Mnemos Terminal — LILYGO T5

Diretório reservado para a migração do firmware Mnemos ao hardware LILYGO T5 4.7".

A implementação ainda não foi consolidada neste repositório. O contrato público de dados e sincronização não deve depender do hardware; a futura implementação T5 deverá consumir os mesmos schemas e protocolos definidos em `spec/`.

Quando o port for iniciado, mantenha código específico de placa em `firmware/t5/` e mova para `firmware/common/` apenas módulos que tenham sido efetivamente validados em mais de uma plataforma.
